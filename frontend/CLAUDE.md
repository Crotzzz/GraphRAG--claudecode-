# GraphRAG 前端项目

## 项目路径

```
D:\vibe coding\GraphRAGAgent\frontend
```

## 启动开发服务器

```bash
cd "D:/vibe coding/GraphRAGAgent/frontend"
pnpm dev
```

启动后访问 **http://localhost:8443**

## 其他命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器（热更新） |
| `pnpm build` | 构建生产版本 |
| `pnpm preview` | 预览生产构建 |

## 技术栈

React 19 + Vite 8 + TypeScript + Tailwind CSS 4

## 1. 产品概述

### 1.1 产品定位

GraphRAG 智能文档问答系统是一个基于**知识图谱 + 大语言模型**的企业级智能文档分析平台。用户上传 PDF、图片、Office 文档后，系统自动完成文档解析、实体提取、知识图谱构建，并提供基于知识图谱的 AI 智能问答能力。

### 1.2 核心目标

| 目标编号 | 目标描述 | 优先级 |
|:--------:|----------|:------:|
| G1 | 实现文档从上传到知识图谱构建的全链路自动化，用户只需拖拽文件即可完成 | P0 |
| G2 | 提供基于知识图谱的 AI 智能问答，回答内容有据可查、来源可追溯 | P0 |
| G3 | 支持知识图谱可视化交互，让用户直观理解文档中的实体和关系 | P0 |
| G4 | 支持多轮对话上下文记忆，用户可连续追问深入分析 | P1 |
| G5 | Agent 推理过程透明化，用户能看到 AI "思考"的过程 | P1 |
| G6 | 支持多设备响应式适配，桌面端三栏、平板两栏、手机单栏 | P2 |
| G7 | 支持暗色模式，减少长时间使用的视觉疲劳 | P2 |

### 1.3 目标用户群体

| 用户类型 | 角色描述 | 核心需求 | 使用频率 |
|----------|----------|----------|:--------:|
| **医生/临床研究人员** | 分析医疗病历、论文文献 | 快速从病历中提取诊断、用药、症状信息 | 高频 |
| **科研人员/分析师** | 分析技术文档、研究报告 | 从技术文档中提取关键实体和关系，辅助研究 | 中频 |
| **企业知识管理专员** | 管理企业内部文档 | 将非结构化文档转为结构化知识，支持决策 | 中频 |
| **法律/合规人员** | 审查合同、法律文书 | 从法律文档中提取条款、义务、期限等关键信息 | 低频 |
| **普通办公用户** | 处理日常办公文档 | 快速了解长文档内容，提取核心信息 | 低频 |

### 1.4 业务痛点

| 痛点编号 | 痛点描述 | 影响 | 解决方案 |
|:--------:|----------|:----:|----------|
| P1 | 长文档（如病历、报告）阅读耗时，人工提取关键信息效率低 | 分析师花费数小时阅读 | 自动解析 + AI 提取，秒级完成 |
| P2 | 大模型直接问答容易产生幻觉，回答缺乏依据 | 决策风险高 | 基于知识图谱的结构化回答，附来源引用 |
| P3 | 文档中的实体关系难以直观理解和发现 | 信息利用率低 | 知识图谱可视化，实体关系一目了然 |
| P4 | AI 问答过程不透明，用户无法判断回答质量 | 信任度低 | SSE 流式推送推理过程，工具调用可视化 |
| P5 | 多次提问需要重复上传和解析，历史无法追溯 | 工作流程断裂 | 对话历史持久化，多轮上下文保持 |

### 1.5 核心场景

#### 场景一：医疗病历智能分析（MVP 验证场景）

```
用户：医生
输入：急诊病历 PDF
流程：
  ① 上传 PDF → 自动解析 → 知识图谱构建（21 个实体，25 条关系）
  ② 用户提问："患者有哪些诊断？"
  ③ Agent 检索知识图谱 → 回答："共确诊 4 项疾病：急性胰腺炎（水肿型）、胆囊结石..."
  ④ 用户追问："用了什么药？"
  ⑤ Agent 保持上下文 → 回答："5 种药物：硝苯地平控释片、生长抑素..."
  ⑥ 图谱中对应的诊断、用药节点高亮显示
  ⑦ 用户查看来源引用，确认回答的准确性
```

#### 场景二：技术文档知识提取

```
用户：研发工程师
输入：API 技术文档 PDF
流程：
  ① 上传文档 → 自动解析 → 图谱构建
  ② 用户提问："文档中涉及哪些技术组件？"
  ③ Agent 返回实体清单和组件关系图
```

#### 场景三：多文档对比分析

```
用户：分析师
输入：多份业务报告 PDF
流程：
  ① 批量上传多份文档 → 分别构建知识图谱
  ② 切换不同文档的知识图谱进行对比
  ③ 分别提问获取各文档的关键信息
```

### 3.2 文档上传→索引→图谱生成流程

```
用户操作                   前端行为                                API 调用
─────────                 ──────                                 ──────

① 拖拽 PDF 到上传区   ──▶  显示上传进度指示                     POST /documents/upload
  或点击选择文件                                                   
                              │                                  
                          显示 TaskItem（状态: pending）
                                                                  
② 轮询任务状态        ──▶  setInterval 每 2s                    GET /documents/{doc_id}
                              │                                  
                          更新进度条百分比
                          更新状态文字:
                          5%  → "MinerU 文档解析中"
                          30% → "内容提取中"
                          45% → "文本预处理完成"
                          70% → "实体提取中（DeepSeek）"
                          80% → "知识图谱构建中"
                          95% → "图谱构建完成"
                         100% → "解析完成"

③ 解析完成          ──▶  自动选中该文档                        GET /kg/{doc_id}
                              │                                 GET /kg/{doc_id}/stats
                          加载知识图谱数据
                          更新统计面板（节点数/关系数/类型数）
                          渲染 D3 力导向图
                          启用 Chat 面板输入框
                          状态栏更新 "已就绪"
```

### 3.3 智能问答交互流程

```
用户操作                   前端行为                                API 调用
─────────                 ──────                                 ──────

① 输入问题            ──▶  校验非空                            POST /agent/stream
  点击发送按钮               添加 user 消息到 Chat
  或 Ctrl+Enter             显示发送中状态
                              │
                          打开 SSE 连接

② Agent 推理过程      ──▶  SSE 事件驱动                    ← SSE: status
  可视化                                                    
                              │                             ← SSE: tool_call
                          显示:「🔍 正在搜索「诊断」...」
                          显示:「🔗 正在查询关系...」
                              │                             ← SSE: token
③ 流式输出回答        ──▶  创建 assistant 消息
  打字机效果                 逐 token 追加到消息内容
                              Markdown 实时渲染（表格/列表/代码）
                              │                             ← SSE: done
④ 回答完成            ──▶  停止 loading 状态
                              │
                          显示来源引用实体列表
                          图谱高亮对应节点                 → 图谱联动
                          更新统计（耗时/来源数）
                              │                             ← SSE: error
⑤ 异常处理            ──▶  显示错误提示
                          保持可重试状态
```

### 5.1 侧边栏交互

| **滚动** | 列表滚动 | 任务超过侧边栏高度 |

### 5.2 知识图谱交互

| 交互 | 行为 | 视觉反馈 |
|------|------|----------|
| **悬停节点** | 显示 tooltip（实体名称+类型+属性预览） | 半透明浮层，节点放大 10% |
| **点击节点** | 高亮该节点及其一度关系，其他节点变暗 50% | 关联节点带光环效果，边加粗 |
| **点击空白处** | 取消高亮，恢复所有节点 | 所有节点恢复 100% 不透明度 |
| **拖拽节点** | 更新节点位置，力模拟实时响应 | 平滑动画 |
| **滚轮缩放** | 画布整体缩放 | 以鼠标位置为中心 |
| **双击空白** | 重置视图为中心 | 平滑过渡动画 |
| **Ctrl+F** | 打开搜索框 | 顶部弹出搜索栏 |

### 5.3 SSE 流式问答交互

| 阶段 | 用户看到的 | 交互状态 |
|:----:|-----------|:--------:|
| **发送前** | 输入框中输入文字，发送按钮可点击 | 输入校验（非空） |
| **连接中** | 发送按钮变为 loading 状态，输入框禁用 | 显示「正在连接...」 |
| **工具调用** | 状态标签显示「🔍 正在搜索「诊断」...」 | 自动滚动到最新状态 |
| **输出中** | 回答内容逐 token 出现（打字机效果） | 自动滚动到最新内容 |
| **完成** | 显示完整回答 + 来源引用 | 输入框恢复，可继续提问 |
| **错误** | 回答区域显示红色错误提示 | 显示「重新发送」按钮 |

### 5.4 图谱-问答联动交互

```
用户提问 → Agent 回答完成
    │
    ▼
后端返回 sources[]（引用实体列表）
    │
    ▼
前端解析 sources，提取实体名称
    │
    ▼
在知识图谱中查找匹配节点
    │
    ├── 匹配到节点 → 高亮+闪烁动画（3 次）
    │                 画布自动缩放以包含所有高亮节点
    │                 切换到「高亮模式」（其他节点半透明）
    │
    └── 未匹配到节点 → 无操作
```

### 5.5 多轮对话交互

| 阶段 | 前端逻辑 | 用户体验 |
|:----:|----------|----------|
| **第一轮** | `thread_id: null` → 后端自动创建 | 正常提问 |
| **后续轮次** | 使用返回的 `thread_id` 发起 `POST /agent/chat` | 无感，追问即可 |
| **刷新页面** | Chat store 从 localStorage 恢复 `thread_id` | 对话消息加载 |
| **切换文档** | 清空当前对话，新建 thread | 提示「切换文档将开始新对话」 |
| **查看历史** | `GET /agent/threads/{id}` 加载历史消息 | 完整对话回放 |

### 5.6 文件上传交互

| 交互 | 行为 | 异常处理 |
|------|------|----------|
| **拖拽文件** | 高亮上传区域虚线边框 | 非支持格式显示 ❌ 提示 |
| **点击选择** | 打开系统文件选择器 | 限制选择文件类型 |
